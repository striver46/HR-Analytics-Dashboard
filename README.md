## 🎯 Project Overview

Ek **interactive Tableau dashboard** jo **8,950 employees** ke HR data ko analyze karta hai. Isse HR team hiring, attrition, demographics, education, performance aur salary ke patterns ek hi jagah dekh sakti hai.

**Business questions jinka answer dashboard deta hai:**

- 📈 Kitne employees hire hue, kitne active hain aur kitne chhod gaye?
- 🔻 Attrition rate kitna hai?
- 🏢 Kaun se departments mein sabse zyada hiring hui?
- 🚻 Workforce ka gender split kya hai aur employees kahan based hain?
- 🎓 Education level, age group aur performance ka kya relation hai?
- 💵 Role, age aur education ke hisaab se salary kaisi hai?

## 🔍 Key Insights

### 🏢 Recruitment by Department

<p align="center">
  <img src="assets/dept_hires.png" alt="New Hires by Department" width="85%">
</p>

- 🥇 **Operations**: 2,429 new hires (sabse zyada)
- 🥈 **Sales**: 1,634 new hires
- 🥉 **Customer Service**: 1,489 new hires
- Top 3 departments milkar hiring ka bada hissa banate hain, isliye recruitment planning yahin focus karni chahiye.

### 📉 Attrition & Gender Split

<img width="1800" height="720" alt="hr_status_gender" src="https://github.com/user-attachments/assets/f5f19ac0-2974-45a8-8ef2-17b0cdd9c34a" />

- **10.79%** attrition (966 terminations) aur **89.21%** active employees
- Gender split: **54% Male** aur **46% Female**
- Geographic view mein employees ka HQ vs Branch distribution bhi dikhaya gaya hai

### 🎓 Education, Age, Performance & Salary

- **Education & Age**: har age group mein education level ka distribution
- **Education & Performance**: performance ratings (Excellent to Needs Improvement) education level ke saath compare kiye gaye
- **Income**: education aur gender ke hisaab se salary comparison, aur Age vs Salary scatter plot role-wise

## ✨ Dashboard Features

| Feature | Description |
|:--|:--|
| 🎛️ **Interactive Filters** | Status, Gender, Location, Hire Date |
| 🖱️ **Click-to-Filter** | Kisi bhi chart par click karke poora dashboard filter karein |
| 📊 **Overview Section** | Active, Hired, Terminated trend + Departments + Location |
| 👫 **Demographics Section** | Gender, Education & Age, Education & Performance |
| 💰 **Income Section** | Education & Gender salary, Age vs Salary |
| 📋 **Details Page** | Employee list: demographics, role, geography, salary, status, tenure |
| 📤 **Export** | PDF / Image export buttons |
